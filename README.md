# Gokularasan — Advanced 3D Engineering Portfolio (Classic)

> **"Engineering in Motion"** — An interactive 3D personal portfolio for **Gokularasan**, Electrical and Electronics Engineering student at **Kumaraguru College of Technology (KCT)**.

---

## ⚡ Overview

This repository hosts the source code for Gokularasan's digital engineering portfolio, combining:
- **Electrical Engineering & Power Systems**
- **Solar Energy & EPC Operations**
- **Embedded Systems & IoT Telemetry (ESP32 / Arduino)**
- **Industrial Technology (Motor Manufacturing, Automation & Spinning Processes)**
- **Sustainability & Climate Action Initiatives**

---

## 🛠️ Technology Architecture

- **Core**: HTML5, Vanilla CSS3, ES6 JavaScript Modules
- **3D Visualization**: Three.js WebGL (Interactive *Engineering Core* with scroll-driven state transformations & inertia physics)
- **Typography**: Space Grotesk, Inter, JetBrains Mono
- **Case Studies**: 
  1. *Real-Time Classroom Energy Monitoring System*
  2. *Smart Cooking Oil Impurity Detection System* (with HIOKI Impedance Analyzer)
- **Document Management**: Dynamic DOCX resume builder and high-resolution document viewer

## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/gokularasan-bot/My-Portfolio-Classic.git

# Navigate into directory
cd My-Portfolio-Classic

# Start any local HTTP server (e.g. Python)
python -m http.server 3000
```
Open `http://localhost:3000` in your browser.
